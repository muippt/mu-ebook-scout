✨ 核心亮点

为什么选 mu-ebook-scout？

🌐

十个内置源，并行搜索

不想为找一本书挨个打开十个网站？一次查询并行问遍下述书源，结果排好序递到你面前。

单源失败绝不拖垮查询
🐙

GitHub 全量书单搜索

现代书的线索常散落在社区书单笔记里。它替你把 GitHub 全站的书单翻一遍，命中网盘目录时连提取码一起给你——工具不碰网盘。

网盘结果严格只给链接
🥇

置信度排序

十个源各说各话，人工比对要翻很久。每条结果打 0–100 分，最合适的排最前——你只管从榜首看起。

无需在十个源之间人工翻找
🔧

三形态共享一个内核

习惯终端就敲命令，用 AI Agent 就让它替你搜，搭了 MCP 客户端就当工具调用——同一个引擎，换着姿势用。

一个内核，三个入口
🧩

custom 源机制（Prowlarr 模式）

内置源之外还想追自己的书源？在配置里加一项就能接入——结果只给链接，由你在自己的浏览器打开，绝不代理下载。

你的书源，你的浏览器
🛡️

显式下载 + 校验把关

一切下载都要你点头，文件到手前还要过 host 白名单、大小上限、文件头校验三道关；零命中也不让你白跑——手动入口和合法借阅/购买渠道一并奉上。

🚀 工作流

四种使用方式

搜索与排序

十源并行找一本书，按置信度排序、按可获得性分组。

触发：bookscout search "书名"

校验下载

下载你选定的一条——host 白名单、100MB 上限、魔数校验。

触发：bookscout get N

MCP 集成

Agent 免终端调用搜索：MCP 客户端配置后即得 search、get 两个工具。

触发：mcpServers · bookscout.mcp_server

Agent Skill 模式

对话式「先搜索、确认后下载」工作流，由 Agent Skill 壳封装。

触发：skills/mu-ebook-scout/SKILL.md
