✨ 核心亮点

为什么选 mu-ebook-scout？

🌐

十个内置源，并行搜索

Project Gutenberg、Open Library、维基文库（中/英）、Standard Ebooks、CBETA、ctext.org、LibriVox、Google Books，加两个中文古籍 GitHub 镜像——并行搜索，优雅降级。

单源失败绝不拖垮查询
🐙

GitHub 全量书单搜索

通过 GitHub 代码搜索 API 检索全站社区书单 Markdown，命中指向网盘下载的目录行；无 Token 时降级为种子仓库直扫。

网盘结果严格只给链接
🥇

置信度排序

按书名/作者匹配度、可获得性、格式计算 0–100 分，最合适的候选排最前。

无需在十个源之间人工翻找
🔧

三形态共享一个内核

CLI（bookscout search / get）、MCP server（pip install mu-ebook-scout[mcp]）、Agent Skill 壳——哪种顺手用哪种。

一个内核，三个入口
🧩

custom 源机制（Prowlarr 模式）

在配置文件里添加自己的书源。custom 源严格只透传：结果只给链接，由你自己在浏览器打开，绝不代理下载。

你的书源，你的浏览器
🛡️

显式下载 + 魔数校验

你不点头就不下载。每次下载经过 host 白名单、100MB 上限、魔数校验三道关卡，通过才算成功。

通过校验才算成功

🚀 工作流

四种使用方式

搜索与排序

十源并行找一本书，按置信度排序、按可获得性分组。

触发：bookscout search "书名"

校验下载

下载你选定的一条——host 白名单、100MB 上限、魔数校验。

触发：bookscout get N

MCP 集成

Agent 免终端调用搜索：MCP 客户端配置后即得 search、get 两个工具。

触发：mcpServers · bookscout.mcp_server

Agent Skill 模式

对话式「先搜索、确认后下载」工作流，由 Agent Skill 壳封装。

触发：skills/mu-ebook-scout/SKILL.md
